# Haier 集成

基于 banto6/haier 1.3.0 修改，向原作者致敬！
电热水器相关功能仅在自用的热水器上进行了安装测试。

1.打开了电热水器控制温度调节的模式选择开关，包括整胆、半胆、增容、四季温水、智能抑菌。

2.打开了预约用水功能。

3.修改字段显示名称以便于理解。

## 安装
1. 把 `custom_components/haier` 放到配置目录，或通过 HACS 添加自定义仓库。
2. 重启 HA。
3. 设备与服务中添加集成。
